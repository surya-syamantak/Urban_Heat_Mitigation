# Chennai data layout

The directory structure mirrors the source project, but starts clean of Nagpur observations, spatial layers, and outputs.

- `raw/`: GCC ward boundary plus downloaded CPCB, ERA5, Landsat, and OSM source data.
- `processed/`: projected GCC wards, AOI grid, sampled rasters, and model-ready tables.
- `external/GHSL_tile_index/`: global tile index used to locate Chennai’s R8_C26 population tile.
- `external/GHSL_population_2020/`: destination for the downloaded Chennai-covering GHSL raster.

Run `python main.py aoi`, then `python main.py wards` and `python main.py prepare_grid`. The AOI and ward inputs are downloaded from the official GCC GIS Ward_Boundary service. Verify the current boundary vintage and reuse terms with GCC before relying on or redistributing results. Other data and analysis outputs are generated by the remaining workflow steps.
